# Mount View English Boarding School — 3D Campus

A browser-based procedural architectural visualization built with TypeScript, React, Vite, Three.js, React Three Fiber and Drei. The scene opens directly into the campus model; it is not a marketing website.

## Run locally

- Install Node.js 20 or newer.
- In this folder run `npm install`
- Start development server: `npm run dev`
- Production build: `npm run build`
- Preview production build: `npm run preview`

## Controls

- Left-drag: orbit
- Scroll / pinch: zoom
- Right-drag: pan
- Use the view chips at the top to focus on a facility, or press Reset view.
- Click buildings and facilities to inspect them.

## Model notes

Dimensions explicitly supplied in the brief are modeled in meters. Where the source plan does not provide survey coordinates or elevations, geometry is an architectural approximation arranged to preserve the stated adjacency and courtyard organization. It is a conceptual visualization, not a surveyed BIM or construction document.
